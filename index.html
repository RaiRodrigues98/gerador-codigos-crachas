Antes de usar na operação

Leia o código de login no campo E-mail: ele contém um Tab ao final para avançar à senha, se o coletor transmitir Tab como tecla. Depois leia o código de senha, sem Tab nem Enter. Se o coletor pressionar Enter, desative o sufixo Enter nas configurações dele.

Qualquer pessoa com o código poderá recuperar a senha. Trate a etiqueta como uma credencial de acesso.
